Installation de la version Light de Mouton Chronicles

< < <

Precedent < < <

Pour installer ce jeu, vous devez etre en possession d'un logiciel permettant de decompresser les archives ZIP (Comme Winzip).

Vous pourrez alors decompresser le fichier contenant les fichiers du jeu (Mouton.zip) sur votre disque dur (ou sur disquette! ). Le repertoire choisi pour la decompression n'a pas d'importance sur le jeu...

 

Demarche a suivre :

  1. Installez Winzip ( si ce n'est pas deja fait...)
  2. Double-cliquez sur le fichier "mouton.zip"
  3. Appuyez sur le bouton "Extract" ou "Extraire"
  4. Choisissez le repertoire d'installation (ou creez un nouveau dossier)
  5. Appuyez sur "Extraire" ou "Extract"

Si vous avez des problemes avec l'installation, prevenez nous......
