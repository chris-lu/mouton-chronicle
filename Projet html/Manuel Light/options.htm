Voici les options disponibles :

Vitalité : Points de Vie de chaque animal ( Plus ceux-ci sont eleves, plus le combat durera longtemps )

Nombre de joueurs : Nombre de moutons par equipes presentes dans le match ( allant de 1 a 8)

Taille du terrain : largeur de la zone de jeu. Plus celle-ci est grande, plus la memoire demandee sera importante !

Niveau : Type de terrain sur lequel evolueront les adorables petites betes !

Attention ! Quelques options ne sont pas accessibles a partir de ce menu. Celles ci se trouvent dans le fichier "mouton.cfg". (comme par exemple le placement au hazard des moutons ( Melange = 0)

Reportez vous a la section "Personnalisation".
