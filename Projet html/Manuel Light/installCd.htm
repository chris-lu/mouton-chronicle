Installation de la version CD de Mouton Chronicles

< < <

Precedent < < <

 

Inserez le CD de Mouton Chronicles dans votre lecteur de CD-ROM. Un menu se lancera automatiquement. Si aucune installation precedente n'a ete trouvee, vous devrez cliquer sur le bouton "Installer" pour lancer le processus d'installation. Si une installation precedente a ete detectee, vous aurez le choix entre "Jouer" a Mouton Chronicles ou "Reinstaller" le jeu...

Demarche a suivre :

  1. Inserez le CD de mouton Chronicles dans votre lecteur de CD-Rom
  2. Cliquez sur "installer" ou "reinstaller".
  3. Suivez les explications...

Si vous avez des problemes avec l'installation, prevenez nous......
