Precedent < < <

 

Cet ecran vous permettra de choisir les equipes qui vont s'affronter. Pour selectionner les equipes, cliquez sur celles-ci. Vous pouvez faire defiler la liste de toutes les equipes en cliquant sur les fleches haut ou bas situees a droite de l'ecran. Les equipes ainsi selectionnees apparaissent en surbrillance. Une fois termine, cliquez sur OK pour commencer le jeu.

Nombre d'equipes minimum : 2

Nombre d'equipe maximum : 12
