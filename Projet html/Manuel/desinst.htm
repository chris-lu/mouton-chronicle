Désinstallation

< < <

Precedent < < <

Pour desinstaller la version light du jeu, il suffit de supprimer le repertoire ou les fichiers ont ete decompresses...

Pour desinstaller la version CD, allez dans le "panneau de configuration" et "Ajout/Suppression de programmes". Cliquez sur "Mouton Chronicles" puis sur desinstaller.

 

Demarche a suivre :

  1. Cliquez sur "Demarrer"
  2. Allez dans "Parametre" puis "Panneau de configuration"
  3. Cliquez sur l'icone "Ajout/Suppression de programmes"
  4. Selectionnez "Mouton Chronicles"
  5. Cliquez sur "Suppression" puis "OK"
