Et oui.... meme dans les jeux les plus nuls, il peut y avoir quelques astuces.....

Astuces :

  • Attention aux chutes car lorsque votre mouton tombe de trop haut, celui-ci peut se faire mal et y laisser son tour de jeu...
  • Apres avoir tire, votre mouton peut encore se deplacer. Ceci peut etre utile pour se mettre a l'abri ou encore eviter son propre missile...
  • On vous a toujours appris a ne pas vous abriter sous les arbres par temps d'orage. Oubliez tous ça! Dans ce jeu, s'abriter sous les points hauts peut vous permettre de rester en vie...
  • Votre mouton est capable de tirer lorsqu'il est dans les airs mais il ne peut pas viser... ceci peut avoir plusieurs utilites mais c'est a vous a decouvrir comment utiliser cette capacite...
  • N'oubliez pas de consulter votre panoplie d'armes ( Voir la rubrique "Commande" ) car des armes peuvent apparaitre selon la sante de votre mouton...
  • Vous pouvez utiliser le vent a votre avantage pour pouvoir atteindre ou tirer dans des lieux tres fermes...
  • Un "sheep code" existe. Serez-vous capable de le trouver ? (si vous trouvez vraiment pas, ecrivez nous !) (allez ! un petit indice : il est compose de 3 touches ! -> ? ? CTRL+ALT+SUPPR ? ?)

Types de parties a essayer :

  • Normale : melange des equipes : OUI ; 35 points de vie ; taille du terrain : 3 ou 4;
  • Cooperation : melange des equipes : NON ; 35 points de vie ; taille du terrain : 3 ou 4;
  • Surpopulation : melange des equipes : OUI ; 10 points de vie ; taille du terrain 1; Nb equipes > 6 ; Nb moutons >6
  • Apocalipse Now : melange des equipes : OUI ; 2 point de vie ; taille du terrain 4;
Attention ! Ces parties ne sont que des idees de jeu, et il est conseille de regler les points de vie en fonction du nombre de joueurs par equipes (plus il y a de moutons dans une equipe, plus il est conseille de diminuer les points de vie...)

Si vous avez d'autres astuces vous pouvez aussi nous les envoyer, nous serions ravis de les inclure dans ce manuel.
