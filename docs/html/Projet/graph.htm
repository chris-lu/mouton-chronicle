Les graphismes ont ete realises a l'aide de nombreux programmes : 3DS Max, Bryce 3D, Paint Shop Pro 6.0, Terragen et ...... PAINT !!!!

3DS Max a ete utilise pour le Logo "Atlantys Team", Bryce 3D et Terragen pour les decors du second plan, Paint Shop Pro pour touts les divers retouches d'images et Paint pour le Decor !!!! (Arbres, Glace, Bonhomme de neige, etc...).

Une des principales difficultes a ete de limiter les couleur sans perte significative de qualite. En effet le mode graphique utilise etant le mode 13h (320x200 et 256 couleurs), il fallait pouvoir modifier les graphismes facilement sans modifier toutes les couleurs a chaque niveau. Le second plan et les decors du terrain sont ainsi limite a 64 couleurs chacun. Voici le nombre de couleurs des element modifables du jeu:

  • Moutons : 32 couleurs
  • Ciel : 28 couleurs
  • 2nd plan : 64 couleurs
  • Decor du terrain : 64 couleurs
  • Terrain : 8 couleurs
  • Astres (Lune, soleil et Terre) : 16 couleurs

Ainsi, les graphismes peuvent facilement etre crees, remplaces ou completes.....

Un petit programme (PalEdit) a ete realise (GnoMaster) en complement des logiciels de retouche d'images (qui n'incluaient pas certaines fonction essentielles...) pour pouvoir modifier les couleurs de la palette dans le jeu (permet les rotations de la palette de couleurs.)
