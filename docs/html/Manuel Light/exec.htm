Version Light :

Pour executez le jeu, allez dans le dossier ou vous avez decompresse le jeu et executez le fichier "mouton.exe". Vous pouvez aussi mettre un raccourci sur le bureau ou dans la barre des taches si vous utilisez Windows. (Voir Aide de Windows).

Version CD :

Inserez le CD de Mouton Chronicles et cliquez sur le bouton "Jouer". Vous pouvez aussi cliquez sur les raccourcis crees lors de l'installation. (Le CD n'est pas requis)
