I) Introduction generale

Voici la forme generale de la declaration des options :

 

-Si une option ne modifie qu'une valeur simple (nombre simple, oui(1) ou non(0), cette option sera sous la forme :

-BLABLA = X

ou "BLABLA" sera le nom de l'option(en majuscule!) et "X" la valeur de cette option...

-Si une option doit renvoyer des valeurs complexes (virgule flottante, valeurs multiples, phrases, etc..)

cette option sera sour la forme (sauf exception qui serons precisées...) :

-BLABLA = X

# 11111 22222 33333 44444 5 6 etc....

# 111' 2222' 3333' ........................

ou "BLABLA" sera le nom de l'option(en majuscule!), "X" le nombre de lignes precedees par # a analyser et "11111" "2222" les valeurs de l'option (le type de ces valeurs sera precise en temps voulu...)

-Tout fichier doit se terminer par

-END

 

II) Modification des parametres du jeu.

Ces parametres se trouvent dans les fichiers "lang.fr" et "mouton.cfg".

"Mouton.cfg" :

-VITALITE Nombre de points de vie de chaque mouton
-JOUEURS Nombre de joueurs dans chaque equipe
-PLANS Largeur de la zone de combat
-SUIVRE Suivre le mouton ?
-LECTCD Specifie le lecteur CD utilise (0 = 1er lecteur CD, 1 = 2nd lecteur CD, etc...
-MELANGE Doit melanger les equipes ?
-CURNIV Niveau actuel
-NIVEAUX Nombre de niveaux suivi de leurs noms precedes par # (voir creation de niveaux)
-MENUCOUL Couleur du menu : Chaque nombre represente l'incrementation successive de chaque couleur (rouge, vert, bleu). vous devez entrer 4 groupes de 3 valeurs....

ex : 0 0 4 augmentra de 4 la couleur bleu pour chaque couleur differente (-1 signifie couleur maximale donc -1 -1 -1 = Blanc...)

"Lang.fr":

-T1 Nombre de phrases dites par les moutons : NE DOIT PAS ETRE CHANGE!

Il existe 5 types de phrases de chaque type et chacune est precedee de #

III) Creation de niveaux

Voici la demarche pour cree un niveau :

  1. Copiez le contenu du dossier "Nouveau" (place dans le repertoire d'installation) vers un autre dossier portant le nom du nouveau niveau (ex : "Titanic") (le nom doit etre inferieur a 8 characteres);
  2. Augmentez de 1 l'option NIVEAUX du fichier "mouton.cfg" et ajoutez a la suite : #Nomduniveau (moins de 8 characteres)
    -NIVEAU =X

    #Titanic
  3. Renommez "nouveau.cfg" en "nomduniveau.cfg" (exemple Titanic.cfg)
  4. Modifiez les option de ce dernier fichier comme suit :
SOL Couleurs du sol (8 au total) : r v b correspond aux valeurs respectives en rouve vert et bleu de chaque couleur.
DECORE Nombre de sprites de Decor. Les valeurs qui suivent cette option correspondent respectivement a la position en X,en Y, la longueur et la hauteur de chaque sprite contenu dans le fichier "decor.pcx"
CIEL Aspect du ciel :

#Backxxxxx.pcx : astre visible dans le ciel. Ces fichiers sont contenus dans le repertoire du jeu.

=0 : Ciel etoile

=1 : Degrade de couleurs : "#r v b ..." : valeurs en rouge vert et bleu. "... Incr incv incb" : valeur d'incrementation de chaque couleurs (nombre a virgule flotante)
BACK Nom des deux fichiers de fond (ex : #Titanic1.pcx et #Titanic2.pcx)
GRAVIE Gravite du terrain (gravite reelle divisee par 200) (virgule flottante)
TRACK Piste audio correspondant a ce terrain
ORAGE Eclairs en arriere plan ?
ESPACE Espacement de chaque elements du decor.

 

 

IV) Particularite des fichiers

  • Tous les fichiers du jeux doivent etre inferieurs a 8 caractere (sans l'extension; ex : "fichiers.ext")

  • Chaque fichier graphique doit etre au format "PCX" et limite a 64 couleurs par fichier (les fichier de second plan doivent avoir les memes couleurs sinon....Surprise !)

  • N'oubliez pas de terminer tous les fichier par "-END" !

  • FAITES ATTENTION AUX INFORMATIONS QUE VOUS ENTREZ OU MODIFIEZ! Toutes erreurs dans les fichier de configuration pourra provoquer un Plantage du programme ! ! !
