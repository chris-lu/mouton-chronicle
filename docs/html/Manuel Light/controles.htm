Les commandes se limitent aux touches suivantes :

[Gauche], [Droite], [Haut] et [Bas] (Souris) : Deplacer le curseur (Menu) ou l'ecran (Jeu)

[Bouton Gauche] (souris) : Augmenter les options

[Bouton Droit] (souris) : Diminuer les options

[Gauche] et [Droite] : Deplacer le petit animal sans defense.

[Haut] et [Bas] : Ajuster le tir a l'aide du viseur.

[Entree] : Faire sauter le pitit mouton..

[Espace] : Tirer. Plus vous appuyez longtemps sur cette touche, plus le tir sera puissant.

[+] : Arme suivante.

[-] : Arme precedente.

[F1] : Affiche le nom de tous les joueurs.

[F2] : Centre sur le mouton qui joue.

[Ctrl]+[Alt]+[Suppr] : Groupement de trois touches assez utile si vous executez le jeu sous windows (et meme si vous ne lancez pas le jeu). Permet le fonctionnement normal de "wintruc 82" ou "wintruc 00". Pour fonctionner, vous devez appuyer frenetiquement sur ces touches....

[Reset] : (Situe sur le boitier de votre PC) Variante de [Ctrl]+[Alt]+[Suppr] car ces dernieres touches ne marchent pas toujours sur "wintdaube 95" ou "win$$$$ 2000".
