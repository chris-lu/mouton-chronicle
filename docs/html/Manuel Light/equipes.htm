Ce menu vous permettra de personnaliser vos equipes.

Pour choisir le nom de l'equipe, cliquez sur "Nom" puis saisissez le nouveau nom et appuyez sur [Entree]. Le processus reste le meme pour le nom des 8 moutons.

Pour changer d'equipe cliquez sur suite ou retour.

Vous pouvez ainsi personnaliser les 12 equipes du jeu.

Une fois fini, cliquez sur OK pour revenir au menu principal.
